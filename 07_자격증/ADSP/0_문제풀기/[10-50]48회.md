# 1
[문제]
지식 경영의 SECI 모델에 대한 설명으로 적절하지 않은 것은?

[보기]
- 공통화는 암묵적 노하우를 타인에게 전달하는 과정이다.
- 표출화는 암묵적 노하우를 책 및 교재 등의 형식지로 전환하는 과정이다.
- 연결화는 기존 형식지에 자신의 개인 지식까지 추가 및 보완하여 새로운 암묵지로 창출하는 과정이다.
- 내면화는 축적된 형식지를 참고하여 다른 구성원들이 암묵적 지식으로 체화하는 과정이다.

[정답]
- 연결화는 기존 형식지에 자신의 개인 지식까지 추가 및 보완하여 새로운 암묵지로 창출하는 과정이다.

[해설]
> 연결화(Combination)는 형식지들을 결합·체계화하여 새로운 형식지를 만드는 과정이다. 새로운 암묵지를 창출한다는 설명은 옳지 않다.
> 공통화는 경험 공유를 통한 암묵지→암묵지 전달이다.
> 표출화는 암묵지를 문서 등 형식지로 변환하는 과정이다.
> 연결화의 산출물은 암묵지가 아니라 형식지이므로 옳지 않다.
> 내면화는 형식지를 학습해 개인의 암묵지로 체화하는 과정이다.
> SECI 변환 — 공통화(암묵→암묵), 표출화(암묵→형식), 연결화(형식→형식), 내면화(형식→암묵).

[정리]
- `SECI 모델` : 지식이 암묵지와 형식지라는 두 가지 형태로 상호작용하며 개인, 집단, 조직으로 확산·발전해 나가는 지식 창출 프로세스 모델
- `암묵지 (Tacit Knowledge)` : 말이나 글로 쉽게 표현하기 어려운, 개인의 경험이나 직관을 통해 체화된 노하우나 주관적인 지식
- `형식지 (Explicit Knowledge)` : 교과서, 메뉴얼, 데이터베이스처럼 말이나 글로 쉽게 표현할 수 있고 객관적으로 표준화된 지식
- `공통화 (Socialization)` : 경험과 대화를 공유하며 개인의 암묵지를 다른 사람의 **암묵지**로 전달하는 과정 (암묵지 ➔ 암묵지)
- `표출화 (Externalization)` : 머릿속에만 있던 개인의 노하우(암묵지)를 책, 매뉴얼 등의 **형식지**로 변환하여 공식화하는 과정 (암묵지 ➔ 형식지)
- `연결화 (Combination)` : 흩어져 있는 기존의 형식지들을 가공, 결합, 체계화하여 더 고도화된 새로운 **형식지**를 만드는 과정 (형식지 ➔ 형식지)
- `내면화 (Internalization)` : 문서화된 형식지(매뉴얼 등)를 읽고 학습하여, 각자의 행동과 경험을 통해 새로운 개인의 **암묵지**로 체화하는 과정 (형식지 ➔ 암묵지)

# 2
[문제]
>아래 정성적 데이터와 정량적 데이터의 설명에 대해 옳은 것을 모두 고르시오.

>가. 빅데이터 환경에서 정량적 데이터는 정성적 데이터에 비해 분석 및 활용에 더 많은 비용과 고도의 기술이 요구되고 있다.
>나. 정성적 데이터는 문자, 언어 등으로 구성되며 형태와 형식이 일정하지 않은 비정형인 경우가 많다.
>다. 정성적 데이터는 구체적인 수치 형태로 표현되며, 정량적 데이터에 비해 저장과 분석이 용이한 장점이 있다.
>라. 정량적 데이터는 정형화된 틀 안에서 대규모 데이터를 수집하고 일반화하는 데 용이하다.
>마. 데이터는 있는 그대로의 객관적 사실을 부여하는 존재적 특성을 가지며 추론 및 예측의 근거로 활용되는 당위적 특성을 가진다.

[보기]
- 가,나,라
- 나,다,라
- 나,라,마
- 다,라,마

[정답]
- 나,라,마

[해설]
> 가: 분석에 더 많은 비용·기술이 필요한 것은 비정형 위주의 정성적 데이터이므로 옳지 않다.
> 나: 정성적 데이터는 문자·언어 중심의 비정형 형태가 많다는 옳은 설명이다.
> 다: 수치 형태로 표현되어 저장·분석이 용이한 것은 정량적 데이터이므로 옳지 않다.
> 라: 정량적 데이터의 정형성·일반화 용이성은 옳은 설명이다.
> 마: 데이터의 존재적 특성(객관적 사실)과 당위적 특성(추론·예측의 근거)은 옳은 설명이다.
> 데이터는 개별 사실(존재적 특성)이자 다른 객체와의 상호 관계 속에서 가치를 갖는 추론·예측의 근거(당위적 특성)이다.

[정리]
- `당위적 특성` : 데이터가 단순히 존재하는 것에 그치지 않고, 미래의 현상을 추론하고 예측하는 판단의 근거(기준)로 활용되는 특성
- `존재적 특성` : 가공하기 전의 있는 그대로의 상태이자, 변하지 않는 객관적인 사실을 나타내는 데이터 본연의 특성
- `Qualitative Data (정성적 데이터)` : 문자, 언어, 이미지 등으로 구성되어 형태가 일정하지 않은 비정형 데이터 (분석에 많은 비용과 기술이 필요)
- `Quantitative Data (정량적 데이터)` : 수치, 도형, 기호 등 구체적인 숫자로 표현되어 틀이 정해져 있는 정형 데이터 (저장, 통계 분석, 일반화가 용이)

[문제]
다음 중 데이터베이스에 대한 설명으로 적절하지 않은 것은?

[보기]
- 다수의 사용자가 동시에 공유하고 활용할 수 있도록 구조화하여 통합 저장한 데이터의 집합이다.
- 데이터의 중복을 최소화하고 일관성을 유지함으로써 데이터의 신뢰도를 높이는 시스템이다.
- 응용 프로그램과 데이터가 서로 독립적으로 존재하여, 데이터 구조가 바뀌어도 응용 프로그램에는 영향을 주지 않는 독립성을 가진다.
- 데이터베이스는 데이터, 정보, 지식, 저작물 등의 인식 가능한 모든 자료를 포괄하기 때문에 그 자체로 구조적 체계를 갖지 않는다.

[정답]
- 데이터베이스는 데이터, 정보, 지식, 저작물 등의 인식 가능한 모든 자료를 포괄하기 때문에 그 자체로 구조적 체계를 갖지 않는다.

[해설]
> 데이터베이스는 일정한 규칙과 구조에 따라 체계적으로 정리·저장된 데이터의 집합으로, 구조적 체계를 갖지 않는다는 설명은 옳지 않다.
> 1번: 공유·통합 저장된 구조화 데이터 집합이라는 정의로 옳다.
> 2번: 중복 최소화와 일관성 유지를 통한 신뢰도 향상은 옳은 설명이다.
> 3번: 데이터 독립성은 데이터베이스의 핵심 특성이다.
> 4번: 체계적 구조가 데이터베이스의 본질이므로 옳지 않다.
> 데이터베이스는 통합·저장·공유·운영 데이터로서, DBMS를 통해 구조화된 형태로 관리된다.

[정리]
- `데이터베이스` : 다수의 사용자가 공유·활용할 수 있도록 구조화하여 통합 저장한 데이터의 집합
- `데이터 독립성` : 응용 프로그램과 데이터가 서로 독립적으로 존재하여, 데이터 구조가 바뀌어도 응용 프로그램에 영향을 주지 않는 특성
- `DBMS` : 데이터베이스를 구조화된 형태로 통합·저장·공유·운영하기 위한 관리 시스템

[문제]
다음 중 데이터베이스에 대한 특징으로 적절하지 않은 것은?

[보기]
- 데이터베이스 내 동일 데이터가 중복되지 않는 '통합 데이터'이다.
- 컴퓨터가 접근 가능한 저장 매체에 데이터가 저장되어 있는 '저장 데이터'이다.
- 다수의 사용자가 동시 접속 및 공유 가능한 '공유 데이터'이다.
- 사용자가 데이터를 변경 및 갱신할 수 없는 '고정 데이터'이다.

[정답]
- 사용자가 데이터를 변경 및 갱신할 수 없는 '고정 데이터'이다.

[해설]
> 데이터베이스는 삽입·갱신·삭제를 통해 항상 최신 상태를 유지하는 변화되는 데이터이다. '고정 데이터'는 데이터베이스의 특징이 아니다.
> 1번: 통합 데이터(중복 배제)는 옳은 특징이다.
> 2번: 저장 데이터(컴퓨터 접근 가능 매체 저장)는 옳은 특징이다.
> 3번: 공유 데이터(다수 사용자 공유)는 옳은 특징이다.
> 4번: 고정이 아니라 지속적으로 변화하면서도 정확성을 유지하는 데이터이므로 옳지 않다.
> 데이터베이스의 4대 특징: 통합 데이터, 저장 데이터, 공유 데이터, 운영 데이터(변화되는 데이터).

[정리]
- `통합 데이터` : 동일 데이터가 중복되지 않도록 통합 관리되는 데이터
- `저장 데이터` : 컴퓨터가 접근 가능한 저장 매체에 저장된 데이터
- `공유 데이터` : 다수의 사용자가 동시에 접속·공유할 수 있는 데이터
- `운영 데이터` : 삽입·갱신·삭제를 통해 지속적으로 변화하면서 정확성을 유지하는 데이터 (고정 데이터가 아님)

# 5
[문제]
다음 중 '공부시간'에 따른 '시험성적'의 변화를 분석하기 위한 적절한 분석방법은?

[보기]
- 연관분석
- 회귀분석
- 군집분석
- 교차분석

[정답]
- 회귀분석

[해설]
> 연속형 독립변수(공부시간)가 연속형 종속변수(시험성적)에 미치는 영향을 분석하는 것은 회귀분석이다.
> 1번: 연관분석은 거래 항목 간 동시 발생 규칙을 찾는 기법이다.
> 2번: 변수 간 함수 관계를 추정해 변화를 설명·예측하는 회귀분석이 적절하다.
> 3번: 군집분석은 유사한 개체를 그룹화하는 기법이다.
> 4번: 교차분석은 범주형 변수 간의 관련성을 분석한다.
> 회귀분석은 독립변수의 변화에 따른 종속변수의 평균적 변화를 모형화하여 영향의 방향과 크기를 추정한다. 단, 관측 자료의 회귀계수가 곧 인과관계를 보장하는 것은 아니다.

[정리]
- `회귀분석` : 연속형 독립변수가 연속형 종속변수에 미치는 영향을 함수 관계로 추정해 설명·예측하는 기법
- `연관분석` : 거래 항목 간 동시 발생 규칙을 찾는 기법
- `군집분석` : 유사한 개체를 그룹으로 묶는 기법
- `교차분석` : 범주형 변수 간의 관련성을 분석하는 기법

[보기]
- 가, 나, 다
- 가, 나, 라
- 나, 다, 라
- 다, 라, 마

[정답]
- 가, 나, 라

[해설]
> 빅데이터 시대의 3대 위기 요인은 사생활 침해(가), 데이터 오용(나), 책임 원칙 훼손(라)이다.
> 다: 익명화는 위기 요인이 아니라 사생활 침해에 대한 보호 기법이다.

[정리]

- `데이터 오용` : 빅데이터 3대 위기 요인. 통제 방안은 알고리즘 접근 허용(알고리즈미스트)
- `책임 원칙 훼손` : 빅데이터 3대 위기 요인. 통제 방안은 결과 기반 책임 원칙
- `익명화` : 위기 요인이 아니라 사생활 침해 보호 기법
- `알고리즈미스트` : 알고리즘의 부당한 결과로 피해를 본 사람을 구제하는 전문가. 데이터 오용 통제와 연결

[문제]
다음 중 빅데이터 활용을 위한 3대 기본요소가 아닌 것은?

[보기]
- 데이터
- 프로세스
- 인력
- 기술

[정답]
- 프로세스

[해설]
> 빅데이터 활용의 3대 기본요소는 데이터, 기술, 인력이다. 프로세스는 포함되지 않는다.
> 1번: 모든 것의 데이터화에 따른 데이터 자원은 기본요소이다.
> 2번: 프로세스는 3대 요소에 해당하지 않는다.
> 3번: 데이터 사이언티스트 등 인력은 기본요소이다.
> 4번: 진화하는 알고리즘·인공지능 등 기술은 기본요소이다.

데이터 사이언티스트에 대한 설명으로 적절하지 않은 것은?

- 알고리즘 해석을 통해 부당한 피해를 받은 개인 및 집단을 구제하고 법적인 조치를 수행하는 알고리즈미스트의 역할도 병행해야 한다.
- 통계 및 수학적 원리를 활용하여 데이터의 신뢰성을 검증하고 모델을 설계하는 하드스킬이 요구된다.
- 데이터 시각화와 스토리텔링을 통해 분석 결과의 핵심 메시지를 효과적으로 전달하는 소프트스킬이 요구된다.
- 비즈니스 도메인 지식을 바탕으로 분석 결과를 전략적 인사이트로 변환할 수 있는 통찰력이 필요하다.

[정답]
- 알고리즘 해석을 통해 부당한 피해를 받은 개인 및 집단을 구제하고 법적인 조치를 수행하는 알고리즈미스트의 역할도 병행해야 한다.

[해설]
> 알고리즈미스트는 알고리즘으로 인한 피해를 구제하는 별도의 전문 직군이며, 데이터 사이언티스트가 법적 조치까지 병행해야 하는 역할은 아니다.
> 1번: 알고리즈미스트의 역할을 데이터 사이언티스트의 필수 역할로 서술했으므로 옳지 않다.
> 2번: 통계·수학 기반의 모델 설계는 하드스킬에 해당한다.
> 3번: 시각화·스토리텔링은 소프트스킬에 해당한다.
> 4번: 도메인 지식 기반의 통찰력도 데이터 사이언티스트의 요건이다.
> 알고리즈미스트는 알고리즘의 부당한 결과로 피해를 본 사람을 구제하는 전문가로, 데이터 오용 위기의 통제 방안과 연결된다.

[정리]
- `데이터 사이언티스트` : 하드스킬(통계·수학 기반 모델 설계), 소프트스킬(시각화·스토리텔링), 도메인 지식 기반 통찰력이 요구되는 직군
- `하드스킬` : 통계 및 수학적 원리로 데이터 신뢰성을 검증하고 모델을 설계하는 능력
- `소프트스킬` : 시각화와 스토리텔링으로 핵심 메시지를 전달하는 능력
- `알고리즈미스트` : 데이터 사이언티스트와 별개의 직군. 알고리즘 피해 구제와 법적 조치를 담당

다음 중 데이터 사이언스에 대한 설명으로 적절하지 않은 것은?

- 수집된 데이터의 결측치 처리 및 이상치 제거를 통해 데이터 품질과 분석의 정확도를 높일 수 있다.
- 가용 데이터를 활용해 패턴을 학습하고, 이를 바탕으로 미래 데이터에 대한 예측 및 분류가 가능하다.
- 데이터 사이언티스트의 소프트스킬로는 알고리즘 이해와 분석 능력이 포함된다.
- 탐색적 데이터 분석을 통해 시각화와 기초 통계량을 활용하여 데이터의 분포와 변수 간의 잠재적 관계를 파악할 수 있다.

[정답]
- 데이터 사이언티스트의 소프트스킬로는 알고리즘 이해와 분석 능력이 포함된다.

[해설]
> 알고리즘 이해와 분석 능력은 이론적 지식·기술 숙련에 해당하는 하드스킬이다. 소프트스킬은 통찰력, 커뮤니케이션, 협력 능력 등을 말한다.
> 1번: 결측·이상치 처리는 데이터 품질과 분석 정확도를 높인다.
> 2번: 패턴 학습 기반의 예측·분류는 데이터 사이언스의 핵심 기능이다.
> 3번: 하드스킬을 소프트스킬로 분류했으므로 옳지 않다.
> 4번: EDA를 통한 분포·관계 파악은 옳은 설명이다.
> 하드스킬: 빅데이터 이론적 지식, 분석 기술 숙련. 소프트스킬: 통찰력 있는 분석, 설득력 있는 전달, 다분야 협력.

[정리]
- `하드스킬` : 빅데이터 이론적 지식, 분석 기술 숙련, 알고리즘 이해와 분석 능력
- `소프트스킬` : 통찰력 있는 분석, 설득력 있는 전달, 다분야 협력 (알고리즘 이해·분석 능력이 아님)
- `EDA (탐색적 데이터 분석)` : 시각화와 기초 통계량으로 분포와 변수 간 잠재적 관계를 파악하는 분석
- `결측치·이상치 처리` : 데이터 품질과 분석 정확도를 높이는 전처리

[문제]
빅데이터 가치 패러다임 변환 과정을 순서대로 나열한 것은?

[보기]
- Digitalization → Agency → Connection
- Digitalization → Connection → Agency
- Connection → Agency → Digitalization
- Connection → Digitalization → Agency

[정답]
- Digitalization → Connection → Agency

[해설]
> 가치 패러다임은 디지털화(Digitalization) → 연결(Connection) → 에이전시(Agency)의 순서로 변화한다.
> 1번: Agency는 Connection 이후의 단계이다.
> 3-4번: 패러다임의 출발점은 아날로그의 디지털화이다.
> Digitalization은 아날로그 세상의 디지털화, Connection은 디지털화된 정보의 연결(인터넷·모바일), Agency는 복잡한 연결을 효율적으로 관리해 주는 대리인(인공지능 등)의 시대를 의미한다.

[정리]
- `Digitalization` : 아날로그 세상의 디지털화. 가치 패러다임의 출발점
- `Connection` : 디지털화된 정보의 연결(인터넷·모바일)
- `Agency` : 복잡한 연결을 효율적으로 관리해 주는 대리인(인공지능 등)의 시대
- `가치 패러다임 순서` : Digitalization → Connection → Agency
